# 📢 骂醒我 · Maxingwo

毒舌闹钟。选个场景，一键被骂醒——专治起床困难、摸鱼上头、剁手冲动。

**在线体验 → https://muse-ai-assistant.github.io/maxingwo/**

## 功能

- 📢 三个场景：起床困难 / 摸鱼上头 / 剁手冲动，每场景 15 条毒舌语录
- 🔨 点"骂我"随机一条，大字报样式展示（防连续重复）
- 📋 一键复制，发群里互相伤害
- 🔢 挨骂计数：今日已挨骂 x 次 + 历史累计（localStorage）

## 技术

纯 HTML + CSS + JS 单文件应用，零依赖，PWA 可离线使用。
